Zero-Server Guarantee

"Your images are processed directly in your browser. CEET does not require an external AI API or cloud OCR service."

1. Local WebAssembly OCR Processing

All optical character recognition is performed inside your browser tab using Tesseract.js compiled to WebAssembly. Your uploaded PNG, JPG, or WEBP images are read into local HTML5 Canvas memory and are never transmitted over the network to any processing server.

2. No External AI APIs or Credentials

CEET does not connect to OpenAI, Gemini, Claude, or third-party cloud OCR endpoints. No API keys, user accounts, or tracking cookies are required to use any feature of the platform.

3. Local IndexedDB Storage

When you convert an image, the extracted spreadsheet rows and metadata are stored exclusively in your browser's local IndexedDB database (ceet_db) so you can reopen past conversions. You may delete individual records or wipe all local history at any time from the History or Settings pages.

About CEET

Deterministic, AI-free document-to-spreadsheet conversion powered by CETA.

CEET was built to solve a simple problem: turning printed tables, receipts, attendance sheets, and exam marks into clean Excel workbooks without uploading private files to cloud AI services.

Unlike cloud LLM converters that can hallucinate digits or impose strict page quotas, CEET combines three proven open technologies directly inside your browser:

  • HTML5 Canvas Preprocessing: Real-time grayscale, contrast/brightness normalization, 3×3 sharpening convolution, rotation, and region cropping.
  • Tesseract.js + Coordinate Clustering: Word-level bounding boxes (x0, y0, x1, y1) grouped into rows and column intervals to reconstruct tabular layouts faithfully.
  • SheetJS (.xlsx) Generation: Standards-compliant Excel workbook creation supporting multiple tabs, numeric type preservation, and auto-sized columns.
